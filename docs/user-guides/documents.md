# Documents - User Guide

## Overview

Documents are the core of your workspace knowledge base. Each document has a verification status and a processing status to help you understand what is ready for search and instruction sets.

## Document list

The Documents tab shows:

- Verification badge: `Verified` or `Unverified`
- Processing badge: `Pending`, `Indexing`, `Indexed`, or `Failed`
- Draft indicator if a document has unpublished changes
- Purpose badge: `Knowledge` or `Instruction`
- Tags (up to two shown, with a "+N" indicator for the rest)

## Filters

Use the toolbar filters to narrow the list:

- **Verification**: All, Verified, Unverified
- **Processing**: All, Pending, Indexing, Indexed, Failed

Filters update the URL so you can share or bookmark filtered views.

## Upload documents

Click **Upload** to open the upload modal. You can drag & drop files or browse to select one.

Supported formats: PDF, DOCX, TXT, MD.

## Create a text document

Click **New Text** to create a text document in a modal editor.

## Status meanings

- **Verified**: trusted, used by default in Search and Instruction Sets
- **Unverified**: not used by default (can be included in Search Links)
- **Indexed**: processing complete, ready for search
- **Failed**: processing error, open the editor to see details
